jubii.7 · Invoice Reader

Track A of the jubii.7 Live Challenge. Everything here is computed from this repo: live endpoints, plus reports written by jubii7 train and scripts/quality.py.

Quality gates

Scan document

Photograph an invoice or upload an image / PDF. Text recognition (Tesseract.js, Arabic + English) runs on your device: the document is never uploaded. The text is then analysed by the package's Python code: line items, quantity × price = amount, dates, TRNs, VAT and line categories.

Recognised text (fix misreads, then analyse)

Model evaluation

Selection by 5×5 repeated stratified k-fold CV (25 fits per model); a 30% stratified hold-out for per-class detail; an unseen challenge set for the honest number.
